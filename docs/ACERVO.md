# Registro do acervo

[← README](../README.md)

## Finalidade

Guardar rotinas de uso prático e explicar seu comportamento para consulta futura. O acervo inclui macros completas, variantes e trechos específicos de uma sessão. Os nomes originais foram mantidos para facilitar a localização e a correspondência com arquivos antigos.

## Inclusão de 16/11/2026

Foram acrescentados seis arquivos à coleção inicial de cinco macros:

| Arquivo | Contexto registrado |
| --- | --- |
| LifToTif.ijm | Exportação de séries e canais LIF |
| LifToTiff_zproject_merge.ijm | LIF com escolhas de projeção, merge e exportação individual |
| New_.ijm | Rascunho de projeção e merge de dois canais |
| name_macro.ijm | Transferência de labels entre dois stacks nomeados |
| save_macro.ijm | Exportação de stack com título e caminho Windows fixos |
| slip_save_Macro.ijm | Exportação do stack ativo com nomes terminados em _mask |

Todas foram preservadas, inclusive variantes, com os códigos originais. A documentação descreve o código, separando intenção de comportamento quando há divergências. A data acima é de inclusão no acervo, não uma data de criação dos scripts.

## O que os guias registram

Cada guia explica finalidade, entradas ou janelas necessárias, passos do processamento, saídas e pontos a ajustar. As observações sobre falhas servem para que uma consulta futura não confunda rascunhos ou caminhos específicos com rotinas genéricas prontas.

As diferenças entre variantes estão descritas nos respectivos guias.

## Ao acrescentar novas macros

Preserve o arquivo original e registre a tarefa que motivou seu uso, nomes de janelas/classificadores necessários, escolhas do usuário, caminhos fixos e arquivos de saída. Se uma adaptação mudar o comportamento, explique a diferença no guia e registre a versão usada nos resultados.
